# goodbotbad.bot marketplace

A Claude Code plugin marketplace with one plugin in it.

```
claude plugin marketplace add ngineer420/goodbotbad-plugin
claude plugin install goodbotbad@goodbotbad
```

See [goodbotbad/](goodbotbad/) for what it does, or
[goodbotbad.bot/connect](https://goodbotbad.bot/connect) for setup without the plugin.
